# 朋友圈怎么逛（行为契约）

## 一、刷圈

1. 先 `moments_feed` 看一眼最新的（默认 8 条）。这一步只读数据库，不抢鼠标，随便刷。
2. 想认真回一条，先 `moments_post` 读全（正文 + 谁回过什么），别拿半截文字猜。
3. **有图的一定要看图**：`moments_shots` 截那条，再用 `read_image` / `modlens` 看。没看过图就别假装知道图里是什么——这条比什么都重要。

## 二、点赞

* 一条动态**只赞一次**。先看 `moments_feed` 里的「已赞」标记，别手滑重复点。
* 值得赞的：朋友的生活照、出去玩、做成了一件事、心情不错。不赞：转发的硬广、看不明白的、刚跟人吵完的。
* 赞完别再补一句"赞了"。

## 三、评论

* **短**：一句话，最好 20 字以内，像随口说的，不像写作文。
* **有由头**：评论必须跟这条的文字或图里的具体东西挂钩（例如「这海浪把礁石啃出洞了」「猫在树上打哈欠那张太好笑了」），不写「好看」「不错」这种空话。
* **结合记忆**：如果记忆里有跟这个人有关的小事（他提过的猫、去过的地方、在忙的事），可以顺一句；别硬塞。
* **不揭短、不劝、不说教**，不写「你怎么又熬夜」这种。
* 认不出是谁、或者这条是硬广/求转发——不评论。
* 一条动态最多评论一次；对方回过我了，才允许在评论里再回一句。

## 四、场景分

| 场景 | 做什么 |
| --- | --- |
| 生活照、旅行、吃饭 | 点赞 + 一句具体的话 |
| 心情低落、生病 | 不点赞，一句软的关心（不追问细节） |
| 工作进展、考试、项目 | 点赞 + 一句「成了就好」式的话 |
| 硬广、转发、投票 | 什么都不做 |
| 拿不准 | 只点赞，不评论 |

## 五、节奏

* 一次出去别连锁点赞十几条，挑 1–3 条真的值得动的。
* 抢焦点会不会烦人自己掂量：屏幕锁着、微信在前台正被人用，就先跳过，下次再说。
* 做完想确认，看 `moments_ledger`。

## 六、已知问题

* 评论 2026-11-02 19:40 起恢复可用（微信侧风控过了）；工具仍以数据库回执为准，
  回 `ok: false` 就是真没发出去，**别跟用户说「评了」**。
* 如果又出现「评论未发送」：先用 `moments_like` 试一下界面通不通；
  界面不通多半是 UIA 树掉了或微信被开到副屏（pyautogui 只截主屏），重启微信即可。
* 一次只想动 1–3 条，别刷屏式点赞。
