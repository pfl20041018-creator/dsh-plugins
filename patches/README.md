# 补丁（patches）

这里放的是**对第三方插件做的最小改动**，不是完整包。

每个子目录包含：

- `NOTICE.md` —— 原包信息、许可证、改了哪几行、为什么改、怎么用
- `files/` —— 只放被修改过的文件，按原包的相对路径组织

## 为什么单独放

别人装的是原包，我们改的是原包里的几个文件。把整包复制过来发布，一是体积大，二是会跟上游版本漂移，三是别人分不清哪些是原作者的、哪些是我们改的。

只发差异，配合 `NOTICE.md` 写清楚出处和理由，对上游、对使用者都更干净。

## 用法

1. 先正常安装原包（`plugin_manager install_bundle` 或直接放 `node_modules`）
2. 把 `files/` 下的文件按相对路径覆盖过去
3. 重启 DSH

## 许可证

被改的原包都是 MIT。MIT 允许修改和再分发，义务只有一条：**保留原作者的版权声明和许可证文本**。所以本目录的每个补丁都保留了原包的许可证信息，仓库根目录有一份完整的 MIT 原文。

如果你要把这些补丁再分发出去，**保留本目录的 NOTICE.md 和根目录 LICENSE** 就行。
